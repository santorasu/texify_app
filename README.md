TeXify is a powerful and lightweight Flutter application designed to extract text from images instantly. Whether it's a book page, a document, or a handwritten note, TeXify converts it into editable digital text using advanced OCR (Optical Character Recognition) technology.
✨ Features
📷 Camera Capture: Capture images directly within the app for instant scanning.

🖼️ Gallery Import: Pick existing images from your device gallery to extract text.

⚡ Real-time OCR: Fast and accurate text recognition using ML Kit.

📝 Multi-Language Support: Optimized for English and Bangla text recognition.

✂️ Crop & Rotate: Built-in image editor to refine the scanned area before extraction.

📋 Copy & Share: One-tap copy to clipboard or share extracted text via social media/email.

🌑 Dark Mode: Fully supported dark theme for comfortable usage.

🛠️ Tech Stack
Framework: Flutter

Language: Dart

State Management: Riverpod

OCR Engine: Google ML Kit (Text Recognition)

Image Picker: image_picker

Cropper: image_cropper
